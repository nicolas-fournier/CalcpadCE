Désambiguïsation avec les mots-clés : un mot-clé (#if,#repeat,#md…) est#**collé** à un nom connu ;# (espace) n'est jamais un mot-clé (GetKeywordrenvoie None) → titre. - **Plot** :$plot/$map en début de ligne restent prioritaires (interceptés avant le classifieur).     Journal¶

    A2 — blocs markdown multi-lignes (#md full)¶

    • Nouveau TryRenderMarkdownBlock dans la boucle Parse : accumule les lignes markdown consécutives (listes, tables, blockquotes, code fences, paragraphes) et les rend en un seul bloc via un pipeline Markdig UseAdvancedExtensions (tables pipe/grid, task-lists). N'engage que si le bloc fait >1 ligne de contenu ; une ligne isolée garde le chemin per-ligne.
    • Lignes à math inline ($…$),$plot, mots-clés, HTML < → Stop (gérées per-ligne).
    • Conflit résolu : | est un caractère d'extension de ligne Calcpad (;|&@:({[) → cassait les lignes de table. En mode _mdFull, l'extension implicite par opérateur est désactivée (seul " _" explicite continue). Garde _loops.Count == 0 (pas d'accumulation dans une boucle).
    • Risque de régression nul : #md full n'est utilisé par aucun exemple/test existant.
    • Tests : MarkdownBlockTests (listes ul/ol fusionnées, table, code fence, blockquote, multi-paragraphes, math après bloc, item isolé, bloc caché sous #if 0, titre+prose).

    A3 — Settings.Markdown (Off / Emphasis / Full)¶

    • Enum MarkdownMode + Settings.Markdown (défaut Off = classique, zéro rupture).
    • Initialize seede _isMarkdownOn/_mdFull depuis Settings ; une directive #md on|off|full dans la source prime à partir de sa ligne.
    • La bascule du défaut expédié (Full par défaut à la livraison) reste volontairement non faite : c'est une rupture de compat .cpd → doit passer par A4 (migration) + accord mainteneurs (CONTRIBUTING).
    • Tests : prose sans directive, math inline évalué, défaut classique, directive prioritaire.
