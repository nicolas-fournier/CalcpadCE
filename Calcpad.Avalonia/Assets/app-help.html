CalcpadCE — Avalonia edition

Cross-platform desktop app · features & keyboard shortcuts

New documents start in markdown-first mode (#md full): prose is the default, and a line is a calculation only when it is an assignment (:=) or delimited math ($…$, $$…$$). The gutter shows ƒ on calc lines, # on headings, and nothing on prose.

Calculation vs prose — one gesture

Ctrl+= · ↔ Calc Toggle the line (or selection) between prose and a calculation. Picks the lightest delimiter for you: an assignment L = 6*m becomes L := 6*m; a bare expression q*L^2/8 becomes $q*L^2/8$; a calc line toggles back to prose.
Click a gutter badgeClick the ƒ / blank badge to flip that line calc↔prose.
Double-click a line numberSame toggle, from the line-number margin.
Type = / * / + / - On a prose line with an operand, proposes converting the line to a calculation.
Auto-calc option When on (options bar), typing name = auto-upgrades the line to name := (reversible with Ctrl+Z).

Editor

Autocomplete Type to get suggestions, colour-coded: your variables (first), units, functions, snippets, directives. Accept with Tab or Enter. Toggle it in View ▸ Toggle autocomplete.
HoverHover a unit, function, constant, or a symbol you defined to see its description / comment.
F12Go to the definition of the variable/function under the caret.
Right-clickContext menu: Cut/Copy/Paste, ↔ Calc, Go to definition, Insert function, Undo/Redo.
Syntax colours variables · units · functions · keywords · numbers.

File shortcuts

Ctrl+N / O / S / Shift+S New · Open · Save · Save As. Open files appear as tabs.
F5Recalculate & show the preview.
File ▸ ExportHTML, Word (.docx), or Print/PDF (via the browser).

Panels (toolbar toggles)

FilesBrowse a folder of worksheets; each .cpd expands into its functions. Insert adds #include for a file or a call for a function (relative paths when the option is on).
KeypadNumbers, operators, functions and Greek letters. = inserts := in markdown mode. A right-hand column lists this worksheet's variables and a units palette (length, mass, force, pressure, temperature °C/K/°F/°R, angle, time, electrical) — click to insert.
AIStreaming assistant with agent mode, image/PDF attachments and persistent memory. Set ANTHROPIC_API_KEY or paste a key.

Snippets & formatting

The Snippets menu (and autocomplete) are mode-aware — markdown vs classic. Each item shows its trigger key. The formatting toolbar adds headings, bold/italic, lists, tables, inline/block math, and ↔ Calc. Compute snippets: plot, vector, repeat, def, convert, beam.

Options bar

Substitute · Format equations · Complex · Adaptive plots · Embed images · Relative paths · Auto-calc · Word template (+ Setup…) · Angles (Deg/Rad/Grad) · Units · Palette. Decimals are set in the top toolbar.

Word template export clones a company template (.dotx/.docx) so the .docx inherits its header/footer, margins, fonts and heading styles. Setup… opens a wizard to choose the templates folder (local or a network share), pick the file, and turn it on. The template is cached locally, so export still works if the share is offline. The CLI accepts --template <path> on a .docx export.
